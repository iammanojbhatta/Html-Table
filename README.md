# 📊 Html-Table — HTML Tables Practice

Clean, working examples of **HTML tables** — rows, columns, `rowspan`, `colspan`, headers and product-style layouts — built while learning web development.

## Open it
Just open `index.html` in any browser. No server needed.

## What it demonstrates
- Table structure: `table`, `tr`, `td`, `th`
- Merging cells with **rowspan** and **colspan**
- A realistic product / price / stock table layout

Perfect practice material for +2 and bachelor-level web technology students.
